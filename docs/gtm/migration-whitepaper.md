# 从 VOS 迁移到 G-VOS：技术白皮书

**面向**：正在运行 VOS3000/VOS3800/VOS5000 的话务运营商与呼叫中心服务商
**目标**：让您在 7 天内、不停机地完成切换，且账目一分不差。

---

## 一、我们理解您的顾虑

VOS 用了十几年不换，不是因为它好，是因为：

1. **数据搬不动**——几千个账户、数万条费率、几十条网关配置，还有历史话单
2. **怕停机**——话务是 7×24 的生意
3. **怕换系统后账算不对**——差一分钱都是纠纷
4. **代理商装机生态**——找谁装的还得找谁拆

这份白皮书逐条回应，每一条都有工具或流程对应，且全部可**在您自己的
环境里先验证再决策**。

## 二、迁移四步法

```
① 体检（半天）      ② 影子导入（半天）
   VOS 数据导出         dry-run 进独立环境
   ↓                    ↓
③ 并行双跑（7 天）   ④ 灰度切换（1 天）
   双系统对账           10% 网关 → 全量
```

### ① 体检——免费的"数据体检报告"

我们的 `gvos-migrate extract` 直读 VOS 数据库/导出文件（**不需要
昆石配合，破解版数据库同样支持**），产出：

- 账户树完整性（含孤儿账户、负余额账户清单）
- 费率表健康度（重复前缀、负费率、非数字字符）
- **语义差异清单**：VOS 与 G-VOS 计费行为不同之处逐条列出，
  每条可选"保持 VOS 行为"或"采用新行为"

您拿到的是一份可以拿着和代理商对质的报告。

### ② 影子导入

数据导入隔离环境（不动生产），同样的数据在 G-VOS 里重建：
账户层级、余额快照、费率表、网关配置。此阶段生产系统零影响。

### ③ 并行双跑——账目一致性的证明

| 模式 | 做法 | 适用 |
|---|---|---|
| 话单回放 | VOS 实际 CDR 输入 G-VOS 计费引擎重算 | 不需要双份话务，成本最低 |
| 话务镜像 | INVITE 镜像同时送两系统（测试网关） | 最真实的验证 |

每日对账报告：逐账户话费差、逐费率命中差、差异归因。
**切换门槛：差异 <0.1% 且全部可解释。达不到不切换、不收费。**

### ④ 灰度切换

- 网关分批：先 10% 流量走 G-VOS 观察 24 小时，再 50%、再全量
- 每一步有回滚预案：网关指回 VOS 即回滚（VOS 侧数据冻结在
  切换时刻，新话务不丢失）
- 整个切换窗口 <30 分钟

## 三、计费语义对照表

我们已经逐条对齐了 VOS 的计费核心语义（这来自对 VOS 逆向
分析的工程投入）：

| 语义 | VOS 行为 | G-VOS 兼容性 |
|---|---|---|
| 计费精度 | 7 位小数，第 8 位进一 | ✅ 完全一致 |
| 步长方案 | 60+6 / 6+6 / 1+1 / N+M | ✅ 完全一致 |
| 前缀匹配 | 最长前缀优先 | ✅ 完全一致 |
| 时段费率 | 夜间/周末覆盖基础价 | ✅ 完全一致 |
| 费率生效 | 定时批量替换 | ✅ 更优：保存即时生效 |
| 实时拆线 | 余额耗尽强制拆线 | ✅ 一致（实测 <1s） |
| 多级代理 | 任意层级级联扣费 | ✅ 一致（含原子回滚） |
| 网关管理 | 失败锁定+下一路由 | ✅ 一致（自动探测+串行切换） |

**默认策略：所有差异点保持 VOS 行为**——您的客户账单在切换日
前后不会有任何变化，这是并行双跑能对平的前提。

## 四、迁移范围

| 数据域 | 迁移 | 说明 |
|---|---|---|
| 账户/多级代理 | ✅ | 层级、费率组、信用额度 |
| 余额 | ✅ | 快照结转；负余额账户导入为 0（欠费留在旧账） |
| 费率表 | ✅ | 前缀/价格/步长/时段窗口 |
| 网关配置 | ✅ | 导入后在管理台确认 SIP 注册参数 |
| 历史话单 | ✅（只读） | 归档查询，不参与计费 |
| SIP 账户密码 | ⚠️ 重建 | VOS 无法导出明文密码；新系统生成新凭据，首日逐账户下发（工具批量生成+通知模板） |
| IVR/回拨业务包 | ❌ 不迁 | 如您有此需求，单独评估（见第六节） |

## 五、迁移后您得到什么

- **API**：账户/费率/CDR/报表全部 REST 化——您自己的运营系统
  可以直接对接（VOS 做不到的第一件事）
- **报表**：日账单、结算对账、网关接通率（ASR/ACD）自动生成
- **实时风控**：频次/日成本/地区准入规则，盗打在锁定发生前拦截
- **套餐引擎**：免费额度、折扣、最低消费——VOS3800 的核心卖点
  之一，我们语义兼容
- **AI 语音对接**：每通电话的音频可以 WebSocket 流式喂给您的
  ASR/外呼机器人管道（已实测对接阿里云百炼实时识别）
- **审计**：每一笔费率修改、充值、配置变更都有不可篡改的记录

## 六、诚实的边界

- **IVR/回拨/卡类**：不迁移。如果您有这块存量业务，我们提供建议
  方案但不承诺在切换窗口内完成（这部分业务建议留在旧系统或
  单独分期）
- **AXB 隐私号**：VOS 生态的旧模式正被 700 号段监管重构；我们按
  新架构实现（运营商 X 号平台直连），不是照抄旧模式
- **H.323**：不支持（SIP-only）；存量 H.323 网关经 SBC 转换接入
