# 设计伙伴演示脚本（30 分钟）

**目标受众**：话务商技术负责人 + 决策者
**环境**：本仓库 `docker compose -p gvos up -d`（演示前起好栈）
**物料**：定价表、迁移白皮书、容量报告（打印/平板各一份）

---

## 开场（2 分钟）

> "VOS 的账您算了十五年。今天 30 分钟，我做四件事：开一个能打电话
> 的新账户、算几笔和 VOS 一样规则的钱、把一份 VOS 导出数据搬进来
> 跑起来、再给您看通话语音实时变文字。全程您手上有鼠标的话可以
> 自己点。"

## 第一幕：开户到通话（8 分钟）——打"装机+代理商"模式

1. **浏览器**打开 `http://127.0.0.1:8080/ui`，输入管理令牌
   → 账户/费率/CDR 三页签走一遍（30 秒，只说"这是全部日常操作"）

2. 现场创建账户："演示客户"
   - **关键台词**："注意这个密码——它只显示这一次。VOS 开户要找
     代理商装机，我们 3 秒。"
   - 记下返回的 `sip_password`

3. **终端**用这个新账户注册并打一通电话（SIPp）：

```bash
# 用返回的密码替换后执行：REGISTER → 200
docker run --rm --network gvos_default -v "$(pwd)/test/sipp:/scen:ro" \
  ctaloi/sipp:latest -sf /scen/register_user.xml \
  -key User <新用户名> -key Pass <返回的密码> kamailio
```

4. CDR 页签刷新 → 新通话的记录出现在表里（PDD、计费秒、费用）

> **停顿点**："每一行账都能对到 SIP 消息级的时间戳。您现在可以
> 拿任何一行回去和您的费率表核。"

## 第二幕：计费语义（7 分钟）——打"账算不对"的恐惧

1. 费率页签把 8613 前缀价格从 0.05 改成 0.025
   → **下一通电话**立即用新价（现场打一通验证 CDR）

> "VOS 换费率要等定时任务窗口。我们保存即生效——但您也可以配置
> 成定时生效，兼容您的运营习惯。"

2. 演示 60+6 步长：66 秒通话计费 66 秒、成本 0.055
   → "和 VOS 一字不差：7 位小数、第 8 位进一。"

3. **余额耗尽强制拆线**（提前把测试账户充值降到临界）：
   通话中途被切，CDR 带 `balance-exhausted` 释放原因

> "盗打发生时，损失止于余额，不是止于月账单。再加一条风控规则
> （现场加：每分钟 3 通封顶），第 4 通直接 403——很多客户拿这个
> 当 IRSF 保险。"

## 第三幕：迁移体检（8 分钟）——打"数据搬不动"

1. 拿出准备好的 VOS 导出样本（`test/data/vos-*.csv`）：

```bash
go run ./cmd/gvos-migrate extract \
  -accounts test/data/vos-accounts.csv -rates test/data/vos-rates.csv \
  -gateways test/data/vos-gateways.csv -out snapshot.json
go run ./cmd/gvos-migrate validate -snapshot snapshot.json
go run ./cmd/gvos-migrate plan -snapshot snapshot.json -out plan.md
```

2. 展示**体检报告**：负余额警告、非数字前缀清洗、孤儿账户拦截

> "这是您自己数据的体检。破解版数据库我们一样读——不需要昆石
> 配合。今天回去就可以在您生产 VOS 库的只读副本上跑一遍，拿到
> 您自己的报告再谈下一步。"

3. `load` 导入 → 管理台里出现导入的账户 → **用导入的账户立即打
   一通计费正确的电话**

> "迁移完的账户马上能打电话、马上在正确的费率上扣钱。这就是
> 并行双跑能对平的前提。"

## 第四幕：AI 媒体面（5 分钟）——超出 VOS 的部分

1. 发起一通带录音的呼叫（管理台录音开关打开）

2. ASR 演示（预置 DASHSCOPE_API_KEY）：

```bash
go run ./cmd/gvos-asr bridge -call <call-id> &   # 挂上实时转写
go run ./cmd/gvos-asr feed -in test/audio/zh-test-16k.wav -call <call-id>
```

3. 终端里语音逐句变成文字："您好，这是一通测试电话……"

> "这是对接了阿里云百炼的真实识别。您的 AI 外呼管道——自建的
> 或买来的——都走同一个 WebSocket 接口。VOS 没有这个东西，
> 这也是为什么 AI 外呼公司都在自建基础设施。"

## 收尾（2 分钟）

> "今天您看到的是：开户、计费、迁移、AI 四件事，每件都是真实
> 系统不是幻灯片。容量报告在这儿——2,000 并发、300 CPS、
> 7 万通零漂移，方法全公开，您可以让自己的工程师复测。
> 下一步建议：把您 VOS 库的只读副本给我们跑体检，报告出来
> 之后，您再决定要不要做 7 天并行双跑。"

**如果对方问价格**：掏定价表，只说一句——"同样 6,000 并发，
VOS3800 是 48.8 万，我们 24.8 万，还带 VOS 没有的东西。"
