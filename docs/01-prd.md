# PRD：G-VOS MVP 产品需求文档

**版本**：v0.1（草案）
**日期**：2026-10-06
**状态**：待评审
**上游依据**：`vos-competitive-analysis.md`（竞品/市场分析）

---

## 1. 一句话定位

> 面向持证话务商、呼叫中心服务商与 AI 语音平台的**云原生、API-first、内置合规的下一代话务运营系统**（软交换 + 计费 + 路由 + 风控），用 1/2 的价格和不存在的迁移成本替换 VOS。

**项目代号**：G-VOS（仓库目录名沿用 gvos）。
**不是什么**：不是话务零售商（不做 CPaaS API 零售，避开腾讯/阿里/Twilio 价格战）；不是 VOS 复刻（不做 H.323 优先，不做客户端/装机交付）。

## 2. 目标客户（ICP）与核心场景

| # | ICP | 现状 | 购买触发 | 核心诉求 |
|---|---|---|---|---|
| ICP-1 | 持证中小话务商/线路批发商 | 跑破解版或老正版 VOS3000 + 灰色代理商运维 | 后门盗打事故、被查处风险、扩容受限 | 正版可审计、稳定、账算得清、迁移不动数据 |
| ICP-2 | 呼叫中心服务商/外包坐席商 | VOS3800/自建 FreeSWITCH，自研计费脚本 | 峰值拨号失败、对账痛苦、AI 外呼客户接入 | 4,000 CPS 突发、多租户账务、开放 API |
| ICP-3 | AI 外呼/语音机器人公司 | 直接挂 Twilio/Telnyx 或拼 Kamailio | 分钟成本、30 CPS 自助上限、欺诈损失 | 高并发拨号+WebSocket 媒体流+成本上限+录音质检 |
| ICP-4 | 出海话务商（东南亚/中东/非洲落地） | VOS + 当地落地关系 | 国内政策挤压、国际客户要求 SLA/防欺诈 | 多币种费率、ASR 路由、反 IRSF、英文界面 |

**服务优先级**：ICP-1 + ICP-2 先行（存量替换，销售确定性最高）；ICP-3 用同一套底座承接（增长期权）；ICP-4 在英文版就绪后开启。

## 3. 非目标（v1.0 明确不做）

- H.323（存量场景用 SBC 网关转换承接，SIP-only 是新系统的架构红利）
- 视频/传真 T.38（P2 之后按客户需求排）
- 模拟卡类（calling card）业务
- 硬件加密狗、Windows 客户端（全 Web + API）
- 自营话务/号码零售（避免与客户竞争+牌照风险）

## 4. MVP 功能规格与验收标准

容量基线（对应定价"标准档"，见 pricing 文档）：**单节点 2,000 并发 / 300 CPS / 3 节点集群 6,000 并发 / 1,000 CPS**。验收以公开压测报告为准（压测方案见 architecture 文档 §8）。

### P0 — 没有就不构成产品（v1.0）

| 模块 | 需求 | 验收标准 |
|---|---|---|
| SIP 接入 | 账户/中继双向：注册认证、Digest/ TLS、IP 白名单 + 无注册中继两种模式 | 1,000 账户注册 < 10s 全量；非法注册 100% 拒绝且有审计日志 |
| 通话路由 | LCR、优先级、网关群组、时段、比例分配、同级负载均衡、失败重试（串行 next-hop）、保护路由 | 1,000 条路由规则下选路 P99 < 5ms；网关失败 300ms 内切换下一路由 |
| 实时计费 | 预付费余额实时扣减、费率前缀最长匹配、6+6/1+1/60+6/N+M、秒级计费 7 位小数第 8 位进一、**余额不足强制拆线** | 通话建立即锁定预估费用；每 10s 批量扣减一次；拆线延迟 < 1s；对账差异 = 0（用回放 CDR 校验） |
| 多租户账户 | 账户/子账户/多级代理（≥5 级），每级独立费率组、扣费、信用额度 | 1,000 级代理链路话单逐级计费正确 |
| 网关管理 | 网关注册/认证、并发/CPS 限额、自动锁定（连续 N 失败锁定 M 分钟）、解锁、健康状态 | 故障网关 60s 内自动锁定并告警 |
| 黑白名单 | 主/被叫、前缀、正则；全局+租户级 | 名单 100 万条，匹配 P99 < 1ms |
| CDR | 全字段话单（含 QoS：MOS 估计、丢包、抖动、PDD、挂断原因映射）、实时查询 API、CSV/Parquet 导出 | CDR 落地延迟 < 2s；30 天在线查询 |
| 报表 v1 | 话费日报/月报、网关接通率（ASR/ACD/PDD）、账户收支、结算对账单 | T+1 自动生成+邮件推送 |
| Web 管理台 | 中/英文；角色权限（超管/运营商/代理商/子账户）；全操作审计日志 | 所有计费/路由/费率变更 100% 审计记录（时间、操作人、IP、前后值） |
| HA | 双机热备（Active/Standby），会话与注册状态实时同步 | 拔电源演练：通话媒体面不断（B2BUA 模式），注册 30s 内恢复，RTO < 60s，RPO = 0（计费数据） |
| 部署 | 一键部署：docker-compose（单机）+ Helm/K8s（集群）| 从裸机到可运营 < 30 分钟，文档化 |
| 安全基线 | 全链路 SIP over TLS、管理面 mTLS 或 token、密码 argon2id、License 云端校验 | 第三方渗透测试通过（v1.0 发布门槛） |

### P1 — 差异化卖点（v1.1-v1.2，发布后 6 个月内）

| 模块 | 需求 | 备注 |
|---|---|---|
| REST API + Webhook | 全资源 CRUD（账户/费率/路由/网关/CDR），事件推送（通话开始/结束/余额告警/网关锁定）；OpenAPI 3.1 规范 | 对标 VOS 无 API 的代差 |
| 实时风控引擎 | 规则化：频次（账户/主叫/被叫地区/网关）、成本上限（单呼/日/月）、地区准入、异常时段；命中动作=拦截/限速/告警 | 卖给 ICP-3 的核心付费点；反 IRSF |
| VOS 迁移工具 | 账户/费率/网关/余额导导入；详见 migration-plan 文档 | 最强销售武器 |
| Prometheus 指标 + Grafana 面板 | 系统与业务指标全套（含 CPS/并发/ASR/网关延迟/余额分布） | 开箱即用 |
| 中文合规包 | 话单留存 ≥30 天一键策略、频控模板（对齐骚扰电话治理）、操作员实名关联、线路白名单台账 | 中国 GTM 卖点 |
| 录音模块（订阅） | RTP 层抓取，混音 wav/mp3，按账户/时段策略，API+对象存储 | VosPower 同名模块对标 |
| 动态黑名单（订阅） | 外部数据源订阅（国内多源小号库/国际 IRSF 库），命中即拦 | VosPower 同名模块对标 |

### P2 — 增长期权（v2.0）

- **WebSocket/WebRTC 媒体流**：fork 音频流给 ASR/TTS/AI 管道（对标 Vapi/Retell 需求），双向、sub-500ms 预算控制
- **隐私号网关**：对接运营商 X 号平台/700 号段接口、阿里云 PNP 兼容 API 绑定/解绑/提前解绑语义
- 智能路由增强：按 ASR 动态路由、网关质量学习（PDD/丢包反馈环）
- IVR 可视化编排、转码节点、SBC 模块独立售卖
- 多币种/多时区/多语言计费（出海完整版）

## 5. 用户旅程关键要求

**开户到通话（ICP-2 示例）**：注册 → 创建账户 → 导入费率表（Excel 模板）→ 添加落地网关 → 测试呼叫 → 看到计费话单。**全流程 ≤ 30 分钟、不联系销售**（这是对 VOS"装机+代理商"模式的直接攻击）。

**迁移日（ICP-1 示例）**：导出 VOS 数据 → 导入工具校验 → 并行运行 7 天（双写对比话单差异）→ 切换。详见 migration-plan。

## 6. 发布计划（18 个月）

| 阶段 | 内容 | 出口标准 |
|---|---|---|
| M0-M3 | 架构 spike：Kamailio+自研计费核心打通、1 通端到端计费通话 | 通话→CDR→扣费闭环 demo |
| M4-M8 | P0 全量 + 中文管理台；内部压测到 2,000 并发/300 CPS | 公开压测报告 v1 |
| M9-M10 | 私有化 alpha：3 家设计伙伴（1 家 ICP-1、1 家 ICP-2、1 家 ICP-3） | 灰度稳定 60 天 |
| M11-M12 | **v1.0 GA**：渗透测试、双机 HA 演练视频、迁移工具 beta、官网+透明定价上线 | 首 10 个付费客户 |
| M13-M15 | P1（API/风控/迁移正式版/录音/黑名单） + 英文版 | 首个国际客户（Sippy 价位段） |
| M16-M18 | P2 媒体流 beta + AI 平台合作（≥2 家 AI 外呼公司接入） | WebSocket 媒体流商用案例 |

## 7. 组织建议（最小配置）

- **研发 5-6 人**：2 后端（Go，计费/路由/账户）、1 电信（Kamailio/媒体集成调优）、1 前端、1 QA 兼压测、1 后期加入的 DevSecOps
- **交付/售前 2 人**：1 名资深话务行业售前（最好挖 VOS/OKCC 生态）+ 1 实施工程师
- **M9 起引入设计伙伴计划**：免费用 6 个月换压测数据+案例授权
- 早期销售动作全部围绕"VOS 替换"定位（SEO/CTI 论坛/CSDN 技术内容战——昆石 17 人打不了内容战）

## 8. 成功指标（GA 后 12 个月）

- 北极星：**付费客户数**（目标 50 家；对标：昆石 21 年 ~4,000 家但含大量一次性低价；我们首年 50 家 = 年化 ¥300-600 万 MRR+授权混合）
- 迁移指标：迁移工具月使用 ≥10 次、迁移成功率 ≥90%、并行期话单差异率 <0.1%
- 技术信任：公开压测报告每季度更新；0 盗版（云端 License）
- 留存：设计伙伴→付费转化 ≥60%；客户 NPS ≥40

## 9. 开放问题（需决策）

1. 是否做**社区版**（开源核心+商业闭源计费，对标 2600Hz/OV500 路线）引流？建议 v1.2 后再评估——见 pricing 文档 §5 的利弊。
2. ICP-4 出海档的启动时点：英文版就绪（M13）即启动，还是等 v2.0 多币种？**建议前者**，用中文客服接华人出海商先行。
3. 双机热备 vs 三节点集群的标配线：v1.0 标配双机（对齐 VOS 心智），K8s 集群作为高阶档卖点。**已建议，待确认。**
