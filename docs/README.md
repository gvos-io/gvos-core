## 文档间关键决策链

竞品分析结论 →
1. 不做 VOS 复刻、打"下一代"（PRD §1-§3：定位与非目标）
2. 研发 80% 投控制平面（架构 §1-§2：开源信令媒体+自研计费路由）
3. 对 VOS 对折定价+透明公示（pricing §1-§2）
4. 迁移工具是 GTM 核心武器（migration §1，工具免费、实施收费）

## 待用户拍板的开放决策

1. 社区版（open-core）做不做、何时做（pricing §5，建议 v1.2 后评估、仅国际市场）
2. 出海启动时点：英文版就绪即启动 vs 等 v2.0（PRD §9，建议前者）
3. 双机热备为 v1.0 标配、K8s 集群为高阶档（PRD §9，架构 §5 已按此设计）
4. 模块订阅价格表的具体数字（pricing §3，草案数字需按首批客户访谈校准）
