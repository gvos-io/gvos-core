# ADR-0001:架构决策记录制度

**状态**:已接受(2026-11-19)

## 背景

2026-11-19 架构评审(促成 02-architecture.md v0.2 重写)后,一批重大决策需要正式拍板:注册状态归属、余额数值表示、时钟纪律、事件载荷治理等。这些决策有明确的决策背景、备选项、结论与后果,散落在对话或规划文档里会丢失"为什么"。

## 决定

建立 `docs/adr/` 目录,每个重大架构决策一条 ADR:

- 编号递增(ADR-0001 起),文件名 `NNNN-slug.md`;
- 字段:状态(已接受/已否决/被取代)、日期、背景、备选项、决定、后果;
- 宪法(02-architecture.md)只引 ADR 编号不复制正文,避免双源漂移;
- 被新决策取代的 ADR 状态改"被取代",不删除。

## 后果

- 每个决策可追溯到"当时为什么这么定";
- ADR 与宪法交叉引用,宪法保持薄;实施细节仍归各规划文档(redis-plan 等)。
